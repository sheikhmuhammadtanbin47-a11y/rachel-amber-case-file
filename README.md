# 📁 Case File № 0422 — The Disappearance of Rachel Amber

An **interactive detective case-board website** about Rachel Amber, the
missing Blackwell Academy student from *Life is Strange*
(DONTNOD Entertainment / Square Enix, 2015).

The visitor reopens the cold case: a MISSING poster, **9 sealed evidence
files** to open one by one, a red-string progress bar, 4 suspects whose final
status stays hidden — and a **Sealed Verdict** that unlocks only when every
file has been opened.

**Created by S M Tanbin Kawnin Raj** — a student project for learning & portfolio.

## 🕵️ How the site works

1. **The Victim** — Rachel Amber's dossier and MISSING poster
2. **The Evidence Board** — click each of the 9 files (EV-01 → EV-09) to open
   it; every file ends with the connection it reveals ("follow the red string")
3. **Progress is saved** in the visitor's browser — leave and come back anytime
4. **The Suspects** — Frank, Nathan, David, Jefferson; their statuses flip to
   the final verdicts when the case is solved
5. **The Timeline** — April 22, 2013 → October 11, 2013
6. **The Sealed Verdict** — locked until all 9 files are opened; then the full
   truth and each suspect's verdict are revealed

## ▶️ Run it on your own computer (no software needed)

No VS Code, no installation. Just open this folder and
**double-click `index.html`** — it opens in your browser and everything works.

## 🚀 Publish it on YOUR GitHub (browser only — no VS Code, no Git)

1. Go to **github.com** and sign in with **your own account**
   (`sheikhmuhammadtanbin47-a11y`)
2. Click the **+** at the top right → **New repository**
3. Repository name: **`rachel-amber-case-file`** → choose **Public** →
   **Create repository**
4. On the new repository page, click **“uploading an existing file”**
5. Drag **all the files from this folder** into the page → **Commit changes**
6. Go to **Settings → Pages**
7. Under “Build and deployment”: Source = **Deploy from a branch**,
   Branch = **main** and **/ (root)** → **Save**
8. Wait 1–2 minutes, then open:
   **https://sheikhmuhammadtanbin47-a11y.github.io/rachel-amber-case-file/**

## ✏️ How to update the site later (still browser only)

Open the repository → click `index.html` → delete it and re-upload the new
version via **Add file → Upload files** → Commit. The live site updates in
about a minute.
